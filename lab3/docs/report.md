## 2. Исследование идеи

Требуемый раздел [Build Guides](https://bubble.io/home/buildguides) перенаправляет на страницу авторизации. После входа нужно изучить 1–2 руководства и приложить 2–3 снимка.

Предварительно изучены открытые материалы Bubble:
- [The database](https://manual.bubble.io/help-guides/data/the-database): Repeating Group с источником данных из поиска.
- [Creating, saving and deleting data](https://manual.bubble.io/help-guides/data/the-database/creating-saving-and-deleting-data): действия Create a new thing, Make changes to a thing, Delete a thing.

Предварительная идея: добавить счётчик записей над Repeating Group после изучения Build Guide; зафиксировать вид до и после. Это ещё не реализовано.

## 4. Data и Workflows

Промпт новой сущности:

```text
Предложи новую сущность для приложения «Список книг», отличную от Book, чтобы можно было реализовать полный CRUD в Bubble. Укажи не менее трёх полей разных типов: text, date, yes/no. Предложи три учебные записи. Не используй плагины и внешние API.
```

Предложение: ReadingLog — дневник чтения. Поля и демонстрационные записи приведены в [data-model.md](data-model.md).

Промпт для UI новой страницы:

```text
На отдельной странице reading_log создай русскоязычный UI для существующего Data Type ReadingLog. Поля: title (text), reading_date (date), finished (yes/no). Добавь форму из Input, Date/Time Picker, Checkbox и кнопку «Добавить». Добавь кнопку «Показать записи», Repeating Group для ReadingLog, в каждой ячейке вывод названия, даты и статуса, кнопки «Изменить» и «Удалить». Добавь Popup Edit с такими же полями и кнопкой «Сохранить». Используй header, body, footer, оформление основного приложения. Не создавай новые типы данных или плагины; нужна только заготовка интерфейса.
```
