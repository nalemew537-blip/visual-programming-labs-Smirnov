# Data: ReadingLog

Новый Data Type: ReadingLog (отдельный от исходного Book).

| Field name | Field type | Назначение |
|---|---|---|
| title | text | Название прочитанной книги |
| reading_date | date | Дата записи |
| finished | yes/no | Книга прочитана полностью |

Три демонстрационные записи для ручного ввода через App Data:

| title | reading_date | finished |
|---|---|---|
| Мастер и Маргарита | 2026-11-20 | yes |
| Маленький принц | 2026-11-21 | yes |
| Дюна | 2026-11-24 | no |

Все данные учебные, без персональной информации. При публичном демонстрационном приложении разрешить отображение ReadingLog в поиске и чтение этих полей в Privacy; не открывать реальные данные пользователей. Создание, редактирование и удаление выполнять через workflows.
