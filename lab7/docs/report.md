# Лабораторная работа №7. Notion

**Студент:** Смирнов Арсений, СДП УИР 241.
**Тема:** учёт 3D-печати в учебной мастерской.

## Генерация модели
Промпт: «Придумай уникальную учебную модель Notion для учёта 3D-печати: три базы, минимум две Relation, Title, Select, Date, Number, Formula и простая Button. Опиши поля и предложи по десять реалистичных вымышленных записей. Без ачивок.»

Ответ ИИ: три сущности — Принтеры, Материалы, Задания. Задание связывается с принтером и материалом; стоимость вычисляется по массе и цене. [Полная схема](model.md).

Уточнения после проверки: цена материала записывается в задании отдельно, чтобы история расчётов не менялась при обновлении справочника. Статусы сведены к трём вариантам; номера P01–P10, M01–M10 и J01–J10 используются для однозначной привязки. Выбраны простая формула умножения и кнопка изменения статуса без условий.

## Данные
Подготовлено по 10 учебных записей: [Принтеры](../data/printers.csv), [Материалы](../data/materials.csv), [Задания](../data/jobs.csv). [Связи](../data/relations.csv). Это файлы для наполнения, а не экспорт из Notion.

- Подготовь 10 строк на каждую сущность и проверь ссылки по кодам.
