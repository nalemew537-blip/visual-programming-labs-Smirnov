# Модель данных: учёт 3D-печати

Названия баз: Smirnov / СДП УИР 241 — Принтеры, Материалы, Задания.

| База | Свойство | Тип |
|---|---|---|
| Принтеры | Название | Title |
| Принтеры | Код | Text |
| Принтеры | Технология | Select |
| Принтеры | Поле печати, мм | Number |
| Принтеры | Состояние | Select |
| Материалы | Название | Title |
| Материалы | Код | Text |
| Материалы | Тип | Select |
| Материалы | Цена за грамм, BYN | Number |
| Задания | Название | Title |
| Задания | Код | Text |
| Задания | Принтер | Relation → Принтеры |
| Задания | Материал | Relation → Материалы |
| Задания | Дата | Date |
| Задания | Статус | Select |
| Задания | Масса, г | Number |
| Задания | Цена за грамм, BYN | Number |
| Задания | Стоимость, BYN | Formula |
| Задания | Завершить | Button |

Формула: `prop("Масса, г") * prop("Цена за грамм, BYN")`.

Кнопка «Завершить»: Edit property → Status/Статус = Готово для текущей страницы. Без условий и действий в других базах.

Представления базы Задания: Table (все записи), Board (группировка по Статус).

Relation: каждое задание относится к одному принтеру и одному материалу; принтеры и материалы могут быть связаны со многими заданиями.

Цена в задании — снимок цены на момент печати. Поэтому она хранится отдельно, а формула не зависит от будущего изменения цены материала. Без Rollup и других ачивок.
