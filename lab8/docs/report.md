## Промпт для ИИ

Создай на Xano бесплатного тарифа учебный workspace lab8-smirnov-api, группа СДП УИР 241, для бронирования учебной медиастудии. Три таблицы: smirnov_241_studios, smirnov_241_equipment, smirnov_241_bookings. Студии: name text, capacity integer, available boolean, location text. Оборудование: name text, category enum (camera, audio, support, light), hourly_rate decimal, available boolean. Брони: title text, studio_id table reference на studios, equipment_id table reference на equipment, start_at timestamp, duration_hours integer, status enum (planned, confirmed, completed), paid boolean. Автоматические id. Создай API group «Smirnov / СДП УИР 241» и пять CRUD-эндпоинтов для брони: GET списка с необязательным query status, GET /{id}, POST, PATCH /{id}, DELETE /{id}. Ответы JSON со статусом и данными, валидация положительных чисел и существования reference, 404 для отсутствующей записи. Без ачивок, без интеграций, авторизации и Middleware.

## Ответ ИИ и проверка модели

Предложены три связанные таблицы: студии, оборудование, брони. Две ссылки из брони обеспечивают связь с обоими справочниками. [Модель данных](model.md), [план API](api.md), [OpenAPI](openapi.json).

После проверки добавлены decimal для почасовой цены, boolean для оплаты/доступности, enum для статуса и категории, timestamp в миллисекундах. Для полноценного CRUD добавлен DELETE; query status выбран как простой фильтр, без ачивки пагинации и сортировки.
