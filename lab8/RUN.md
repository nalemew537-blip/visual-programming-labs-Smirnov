# Реализация в Xano

1. Открыть https://www.xano.com/, зарегистрироваться на бесплатном тарифе. Создать workspace lab8-smirnov-api.
2. Использовать AI при создании workspace либо создать таблицы по docs/model.md вручную. Промпт: docs/xano-ai-prompt.txt.
3. Импортировать три CSV из data/ в порядке studios, equipment, bookings; проверить reference.
4. Создать API group «Smirnov / СДП УИР 241» и пять endpoint по docs/api.md, используя CRUD-шаблоны Xano.
5. Выполнить тесты в Run & Debug, открыть Swagger, сохранить фактическую ссылку и скриншоты. Только учебные данные.
6. Экспортировать workspace, если это доступно на бесплатном тарифе.

Документация: https://www.xano.com/learn/creating-database-tables/ и https://www.xano.com/learn/xano-building-custom-crud-api-endpoints/.
