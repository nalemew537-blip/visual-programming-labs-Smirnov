# Бронирование номера в отеле

**Участники:** клиент, система бронирования, платёжный сервис, сотрудник отеля.

1. Клиент отправляет заявку с датами проживания.
2. Система проверяет даты и рассчитывает стоимость проживания; неверные даты клиент исправляет до продолжения оформления.
3. Система проверяет наличие свободных номеров.
4. Если номера нет, клиент получает отказ и процесс завершается.
5. Если номер есть, система предлагает оплатить бронирование.
6. Клиент вводит платёжные данные, а платёжный сервис проверяет их и обрабатывает оплату.
7. Если оплата не прошла, система сообщает об ошибке и завершает оформление.
8. При успешной оплате одновременно выполняются два действия: сотрудник подготавливает номер к заезду, а система отправляет подтверждение клиенту.
9. После завершения обоих действий система завершает оформление бронирования.

**Ветвления:** наличие свободного номера и результат оплаты. **Параллельные действия:** подготовка номера и отправка подтверждения.
