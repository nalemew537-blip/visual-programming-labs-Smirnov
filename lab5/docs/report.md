## Выбранный трек

Трек C — Typebot, учебный FAQ-бот `lab5-smirnov-bot — СДП УИР 241`. В качестве основы выбран [официальный шаблон FAQ](https://typebot.com/templates/faq), исходный JSON сохранён в [template-before.json](../exports/template-before.json). [Источник и атрибуция](../template-source.md).

## Выполненные изменения в JSON

- Русифицированы тексты, кнопки, названия групп и поле ввода.
- Добавлены запрос имени, обращение по имени и установка учебной группы.
- Добавлены переменные Имя, Вопрос, Температура, Группа.
- Добавлен Condition: если вопрос равен «расписание», отдельная ветка с инструкцией; иначе стандартное завершение.
- Добавлен HTTP Request к Open-Meteo, GET без токена, отображение температуры в Гродно. Запрос не передаёт имя, группу или вопросы пользователя.
- Изменена цветовая тема и метаданные. Брендинг платформы сохранён.
- Сохранены переходы и возврат в меню исходного шаблона.

[Подготовленный JSON для импорта](../exports/flow-01-faq.json). Проверены ссылки между группами, блоками, рёбрами и переменными ([результат](validation.json)); выполнение в Typebot пока не подтверждено.

## Примеры AI-промптов

1. Русифицировать FAQ-шаблон, сохранив связи и идентификаторы.
2. Добавить ввод имени и переменную учебной группы.
3. Создать условную ветку для вопроса «расписание» и обычное завершение.
4. Добавить HTTP Request к открытому погодному API и переменную температуры.
5. Настроить спокойную синюю тему интерфейса.

## Интеграция

GET https://api.open-meteo.com/v1/forecast, latitude=53.6693, longitude=23.8131, current=temperature_2m, timezone=Europe/Minsk. Ответ JSON; поле data.current.temperature_2m сопоставляется переменной Температура. При отсутствии значения сообщение информирует о недоступности сервиса.
